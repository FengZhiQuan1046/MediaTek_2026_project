\begin{abstract}
  Selective state-space models (SSMs) offer efficient sequence processing for recommendation, yet item-level modeling can become \emph{nearsighted}. In our preliminary analysis, ranking influence concentrates on recent interactions, which are also more textually aligned with the next item; older items often have negligible or negative influence when modeled individually. However, earlier interactions can still reveal recurring preferences at a coarser level. We propose RIBS (\emph{R}ecommendation via \emph{I}ntegrated \emph{B}ehavioral \emph{S}ignals), which coordinates a Short-Term Recommender Agent and a Long-Term Preference Agent. Both agents share a common backbone while specializing through distinct LoRA adapters in a multi-LoRA architecture. The former encodes a recent item window, whereas the latter maps the available history to learned preference prototypes and models their transitions. Both use separate Mamba-style selective-state updates and LoRA banks. A Coordinator Agent fuses their states and scores using predicted preference changes and entropy-based certainty. Shared item representations combine cached features from a frozen Mamba text encoder with optional LightGCN embeddings. All enabled agents and shared components are trained together in a single supervised stage using multi-step next-item ranking and preference auxiliary losses. We evaluate the resulting model with full-catalog ranking on four Amazon Reviews 2023 categories.
\end{abstract}

\section{Introduction}
Sequential recommendation must infer what a user wants next from a history that mixes recurring interests, short-lived goals, and changing tastes. The latest interactions can indicate immediate intent, whereas earlier interactions may reveal preference patterns that recur across distinct items. A single item-level summary must resolve both timescales. We instead assign these sources of evidence to separate agents and combine their predictions. Item semantics are computed once with a frozen pretrained Mamba text encoder \citep{Mamba} and cached, so ranking does not require repeated text-model inference.

We study a tendency for item-level recommendation signals to concentrate near the end of an interaction sequence, which we call \emph{nearsightedness}. Preliminary diagnostics show that the most recent interactions carry much of the measured item-level signal, while more distant items can still share a text-derived preference-proxy cluster with the next item. For example, a user may interact with several running products and then browse camping equipment: the latest items can indicate immediate intent, while recurring product themes provide a coarser view of preference. This motivates modeling recent items directly and representing preference patterns separately, without assuming that extending the item-level input will make older evidence useful.

We propose RIBS (\emph{R}ecommendation via \emph{I}ntegrated \emph{B}ehavioral \emph{S}ignals), a multi-agent architecture implemented by multiple, disjoint LoRA banks. The \emph{short-term recommender agent} reads the latest $W$ items through a Mamba-style selective state update. The \emph{long-term preference agent} reads the available history up to the configured maximum, maps its items to learned soft prototypes, and runs a separate LoRA-adapted selective state update over that prototype trajectory. It predicts the next preference distribution and the likelihood of a preference change. The \emph{coordinator} uses its own LoRA modules to mix both agent states and scores according to this context. The preference agent therefore has a full-history input even when no direct long-horizon item agent is present.

The agents share a projected item space constructed from cached Mamba text features and LightGCN~\citep{LightGCN} item embeddings. Their selective-state recurrences and LoRA parameters remain separate, with the LoRA banks adapting the online recommendation modules rather than the frozen pretrained Mamba text encoder. This design provides distinct inputs and adaptation paths for the two agents, while the coordinator learns their relative contributions to candidate ranking. The agents and coordinator share item projections and are jointly optimized with multi-step next-item ranking, preference supervision, contrastive alignment, and state-diversity regularization.

We study the contribution of recent item behavior, full-history preference transitions, and their coordination using full-catalog ranking and module ablations. Our methodological contributions are a multi-LoRA realization of these three agent roles, separate selective-state encoders for recent items and long-term preferences, and a single-stage supervised objective that trains the enabled components together.

\section{Related Work}
\paragraph{Sequential representation learning.}
Sequential recommenders first model user behavior as ordered item interactions. SASRec~\citep{SASRec} uses self-attention to select relevant past items, BERT4Rec~\citep{BERT4Rec} learns bidirectional sequence representations with masked-item prediction, and TiSASRec~\citep{TiSASRec} incorporates time intervals. These models establish sequence context as a source of next-item evidence. Text-aware work adds semantic information to this setting: Recformer~\citep{Recformer} represents item attributes as language, EasyRec~\citep{EasyRec} aligns textual and collaborative representations, and BLaIR~\citep{BLaIR} learns recommendation-oriented item representations from text. This line of work motivates our shared item space, in which cached text features complement collaborative embeddings. Related text-based recommendation work also includes UniTRec~\citep{UnitRec}, and MAPLE~\citep{MAPLE}, which study text-to-text recommendation, and explanation generation, respectively. LLM-based approaches extend semantic modeling to recommendation: ELMRec~\citep{ELMRec} models higher-order interactions, while D$^3$~\citep{D3} studies decoding bias and recommendation diversity. Our focus is on ranking items from interaction histories using precomputed language representations.

\paragraph{Selective state-space models.}
Mamba~\citep{Mamba} uses input-dependent state updates and hardware-aware scans to process long sequences efficiently. This efficiency is relevant to recommendation, where user histories must be encoded at scale. Mamba4Rec~\citep{Mamba4Rec} and SIGMA~\citep{SIGMA} apply selective state-space modeling to interaction sequences, while T2ARec~\citep{T2ARec} uses an SSM to adapt to shifts in user interests. These methods motivate efficient behavioral modeling. In our setting, a pretrained Mamba encoder instead produces frozen item-text features once; the ranker combines those cached features with separate recent-behavior and preference-transition representations.

\paragraph{Graph-augmented recommendation.}
Interaction graphs provide collaborative evidence that item text alone cannot capture. LightGCN \citep{LightGCN} propagates embeddings over the user-item interaction graph; we use its item embeddings alongside cached text features in the shared item space. RLMRec \citep{RLMRec} aligns LLM-derived semantic profiles with collaborative representations, and LLMRec \citep{LLMRec} augments user-item graphs with LLM-generated information. M2GRec \citep{M2GRec} combines Mamba sequence modeling with item-transition and user-item graphs, connecting efficient sequence modeling with collaborative structure. Other graph-augmented recommendation work uses different relations: CoLaKG \citep{CoLaKG} and K-RagRec \citep{K-RagRec} incorporate external knowledge graphs, while GeoMamba \citep{GeoMamba} and STMamba-GC \citep{STMamba-GC} model geographical and spatiotemporal relations for POI recommendation. These studies provide context for graph-enhanced recommendation.


\paragraph{Low-rank adaptation.}
LoRA \citep{LoRA} parameterizes weight updates with two low-rank matrices while keeping the pretrained backbone frozen, reducing fine-tuning memory without modifying the original model weights. This property enables multiple LoRA adapters to share a single backbone, supporting efficient multi-task and multi-agent applications \citep{MapCoder-Lite}.

\subsection{Problem Definition}
Let $\mathcal I$ be the item catalog and $\mathcal H_{u,t}=(i_1,\ldots,i_t)$ the interactions observed before predicting the next item for user $u$. The available model history is $\overline{\mathcal H}_{u,t}$, the last $T_P=\min(t,H_{\max})$ interactions, where $H_{\max}$ is the configured maximum. The short-term recommender agent receives only the last $T_S=\min(T_P,W)$ interactions of $\overline{\mathcal H}_{u,t}$, whereas the long-term preference agent receives all $T_P$ interactions. A coordinator combines their candidate scores into $z(u,i\mid\overline{\mathcal H}_{u,t})$ for $i\in\mathcal I$. ``Full history'' below means the entire available prefix up to $H_{\max}$; no agent sees held-out future interactions.

\subsection{Preliminary Analysis}
\label{sec:preliminary}

Figure~\ref{fig:preliminary} combines three text-based diagnostics, panels (a), (c), and (d), with a history-deletion diagnostic, panel (b), from a trained full-history ranker using Mamba item-text features and LightGCN collaborative representations. Lag 1 is the last observed item before the target. In panel (a), the vertical axis is the historical item's text cosine similarity to the next item minus the mean similarity of popularity-matched control items, divided by a category-wide cosine standard deviation. Thus, positive values indicate greater text similarity than the matched controls. In panel (b), the vertical axis is the change in the next item's score minus the mean score of fixed sampled negatives when one historical item is deleted; positive values mean that retaining that item increases this ranking margin. In panel (c), the vertical axis is the percentage of each user's positive excess text similarity from panel (a) contributed by the most recent $k$ positions, averaged over users; the denominator includes up to 100 observed positions. This percentage describes text association, not the trained model's attribution. Appendix~\ref{app:preliminary_diagnostics} gives the exact estimators, sampling, and uncertainty intervals.

The next item has its strongest text-based semantic association with the most recent interactions, and this association falls quickly as lag grows (Figure~\ref{fig:preliminary}a). The deletion-based change in the sampled-slate margin is likewise concentrated in roughly the latest four positions; older positions are near zero and can be negative in the plotted categories (Figure~\ref{fig:preliminary}b). The cumulative positive text-similarity excess reaches approximately 80\% within the latest four items (Figure~\ref{fig:preliminary}c). These descriptive observations motivate separating direct item-level evidence from coarser preference evidence.

The weak item-level signal at longer lags raises a more specific question: can older interactions remain informative when represented by a recurring interest rather than an exact item? For Figure~\ref{fig:preliminary}d, we fit 32 MiniBatchKMeans groups to hashed item-text features from sampled training items and assign each usable item a hard group label $c(i)$. 
% This is a model-free preference proxy: it is independent of the RIBS preference transition encoder, uses neither next-item ranking supervision nor the Mamba and LightGCN item vectors, and differs from the learned soft prototype assignments in RIBS. Two different items can nevertheless share a proxy group.

To test whether this coarser representation retains information at longer lags, let $y_u$ be user $u$'s next item, and let $p_{u,B}$ be the fraction of that user's usable, control-matched historical positions in lag bin $B$ for which $c(i)=c(y_u)$. Let $\mathcal C_u$ be the distinct proxy-group labels in the user's analyzed history. We compare the match fraction with $b_u=\mathbf{1}[c(y_u)\in\mathcal C_u]/|\mathcal C_u|$, the probability of a match when drawing uniformly from those labels. Panel (d)'s vertical axis is the excess match probability, in percentage points:
\begin{equation}
 E_B=\frac{100}{|\mathcal U_B|}\sum_{u\in\mathcal U_B}
 \left[p_{u,B}-b_u\right],
\end{equation}
where $\mathcal U_B$ contains users with at least one usable, control-matched position in bin $B$. A positive value means that past items in that bin share the next item's proxy group more often than this user-specific uniform-label reference. Appendix~\ref{app:preliminary_match} specifies the within-user averaging, group fitting, and chance reference.

Figure~\ref{fig:preliminary}d shows that this excess proxy-cluster match does not always fade with distance: it rises again at longer lags in most categories. This suggests that coarse text similarity can remain visible where direct item-level evidence is weak; it does not establish that the trained RIBS preference encoder uses those older interactions. The inverse-history control in Appendix~\ref{app:preliminary_inverse} retrains the Mamba+LightGCN ranker on reversed histories and repeats the text diagnostics in that order. It helps distinguish the relevance of originally recent items from a tendency to concentrate model influence near the end of the input. Together, these diagnostics motivate reading the full history through a coarser preference representation while limiting direct item-level modeling to the recent window.

\subsection{Multi-Agent RIBS}
\label{sec:ribs}

\subsubsection{Task and Shared Item Space}
The two specialist agents and the coordinator use a common item representation $e_i\in\mathbb R^d$. The short-term recommender agent processes item vectors in the recent suffix; the long-term preference agent processes prototype-weighted vectors formed from every item in $\overline{\mathcal H}_{u,t}$. The coordinator combines their resulting states and candidate scores.

For each item, a frozen Mamba text encoder produces a cached feature $f_i$. A trainable projection maps it to dimension $d$; when enabled, LightGCN \citep{LightGCN} adds a collaborative embedding from the training interaction graph. Their normalized combination forms the shared item vector $e_i$. Text pooling and graph construction are specified in Appendix~\ref{app:implementation}.

RIBS is a multi-agent model implemented through three disjoint LoRA banks: one for each specialist and one for the coordinator. For adaptation module $j$, the LoRA residual is
\begin{equation}
 y_j=\mathcal R_j(x)=\frac{\alpha_{\mathrm{LoRA}}}{r}B_j A_j\operatorname{Dropout}(x),
\end{equation}
Here $A_j$ and $B_j$ are the rank-$r$ input and output projections. The three LoRA banks adapt the online recommendation components while the pretrained text encoder remains frozen. Parameter dimensions, initialization, and other trainable components are detailed in Appendix~\ref{app:implementation}.

\subsubsection{Short-Term Recommender Agent}
The short-term recommender agent $S$ processes the $T_S$ recent item vectors $y_k^{(S)}=e_{i_{t-T_S+k}}$. Both specialist agents use the same \emph{form} of Mamba-style diagonal selective-state update, but have separate parameters and LoRA banks. For agent $m\in\{S,P\}$ with input $y_k^{(m)}$, the core update is
\begin{align}
 h_k^{(m)}&=a_k^{(m)}\odot h_{k-1}^{(m)} +(1-a_k^{(m)})\odot\widetilde h_k^{(m)},\notag\\
 o_k^{(m)}&=g_k^{(m)}\odot h_k^{(m)} +(1-g_k^{(m)})\odot y_k^{(m)}.
 \label{eq:state_update}
\end{align}
Here $a_k^{(m)}$ is the input-dependent retention factor, $\widetilde h_k^{(m)}$ is the candidate state, and $g_k^{(m)}$ is the output gate. The final short-term state is $s_S=\norm{o_{T_S}^{(S)}+\mathcal R_{\mathrm{out},S}(o_{T_S}^{(S)})}$. Agent $P$ uses the same recurrence form on prototype-weighted inputs, with separate parameters. This online state update is distinct from the frozen Mamba text encoder; the gate computations and state initialization are given in Appendix~\ref{app:implementation}.

\subsubsection{Long-Term Preference Agent}
The long-term preference agent $P$ reads all $T_P$ interactions through learned preference prototypes. Let $C\in\mathbb R^{M\times d}$ have row-normalized learned prototype vectors. For the $k$th item in $\overline{\mathcal H}_{u,t}$, it forms a soft assignment and a prototype-weighted input,
\begin{align}
 q_k&=\softmax\!\left(C\norm{e_{i_k}}/\tau_p\right),\notag\\
 y_k^{(P)}&=C^\top q_k.
\end{align}
Agent $P$ applies its own selective-state recurrence above to $(y_1^{(P)},\ldots,y_{T_P}^{(P)})$ and obtains
\begin{equation}
 v_P=\norm{o_{T_P}^{(P)}+\mathcal R_{\mathrm{out},P}(o_{T_P}^{(P)})}.
\end{equation}
With $q_{T_P}$ as the current preference assignment, two trainable heads predict the next distribution and change probability:
\begin{align}
 \widehat q_{t+1}&=\softmax(W_n v_P+b_n),\notag\\
 \rho_t&=\sigma\!\left(w_c^\top[v_P;q_{T_P}]+b_c\right).
\end{align}
The resulting ranking state is
\begin{equation}
 s_P=\norm{C^\top\widehat q_{t+1}+\mathcal R_{\mathrm{state},P}(C^\top\widehat q_{t+1})}.
\end{equation}
The prototypes and prediction heads are trained with the recommendation model. Each specialist scores candidate $i$ by
\begin{align}
 z_m(u,i)&=\kappa_m s_m^\top e_i,\notag\\
 \kappa_m&=\min\{\exp(\theta_m),20\},\quad m\in\{S,P\}.
\end{align}

\subsubsection{Coordinator Agent}
The coordinator $C$ fuses both specialist states and their candidate scores. It receives the predicted preference-change probability $\rho_t$ and the concentration $c_t=1-H(\widehat q_{t+1})/\log M$, where $H$ is entropy. Write $r=[s_S;s_P]$. The two mixing weights are
\begin{align}
 b_P&=\theta_P+w_{\mathrm{ctx}}^\top[\rho_t;c_t]+b_{\mathrm{ctx}},\notag\\
 (w_S,w_P)&=\softmax\!\left(\mathcal R_{\mathrm{mix},C}(r)+[0;b_P]\right).
\end{align}
The coordinator then forms its own state and score:
\begin{align}
 s_C&=\norm{w_Ss_S+w_Ps_P+\mathcal R_{\mathrm{state},C}(r)},\notag\\
 \widetilde s_C&=\norm{s_C+\mathcal R_{\mathrm{score},C}(s_C)},\notag\\
  z_C(u,i)&=\kappa_C\widetilde s_C^\top e_i,\notag\\
  \kappa_C&=\min\{\exp(\theta_C),20\},\notag\\
 z(u,i)&=z_C(u,i)+w_Sz_S(u,i)+w_Pz_P(u,i).
\end{align}
The coordinator uses a separate LoRA bank to adapt mixing, state construction, and candidate scoring. Its initialization and the scoring rules when components are disabled are given in Appendix~\ref{app:implementation}.

\paragraph{Catalog calibration at inference.}
At evaluation, training-item popularity and adjacent-item transition counts provide additive catalog priors to the neural score. The exact calibrated score and treatment of missing transitions are specified in Appendix~\ref{app:implementation}.

\subsubsection{Training Objective}
\paragraph{Multi-step ranking.}
For each sampled prefix, we collect up to $F$ future items from the training history only. Their weights are $a_j=\eta^{j-1}/\sum_{k=1}^{F'}\eta^{k-1}$, where $F'\leq F$ is the available horizon. With candidate slate $\mathcal S$ and target position $p_j$, a ranking head minimizes
\begin{equation}
 \mathcal L_{\mathrm{rank}}(z)
 =-\sum_{j=1}^{F'}a_j\log\softmax(z_{\mathcal S})_{p_j}.
\end{equation}
Bounded training prefixes are resampled each epoch. Candidate slates contain future targets together with model-mined, random, and in-batch negatives. The handling of repeated targets, negative sampling, and the optional full-catalog objective are described in Appendix~\ref{app:implementation}.

\paragraph{Preference supervision.}
The immediate next item's prototype assignment supplies a detached target $q^+=\sg(q(i_{t+1}))$. We minimize $\mathcal L_{\mathrm{pred}}=D_{\mathrm{KL}}(q^+\Vert\widehat q_{t+1})$. The transition target is
\begin{equation}
 y_{\mathrm{shift}}=\frac{\operatorname{JS}(\sg(q_t),q^+)}{\log 2},
\end{equation}
and $\mathcal L_{\mathrm{shift}}$ is binary cross-entropy between this soft target and $\rho_t$. This target measures a change in learned item assignments, rather than an annotated change in user intent.

Three additional terms encourage balanced, distinct, and sharp prototype assignments. Together with next-preference prediction and transition supervision, they form
\begin{align}
 \mathcal L_P={}&\lambda_p\mathcal L_{\mathrm{pred}}
 +\lambda_t\mathcal L_{\mathrm{shift}}
 +\lambda_b\mathcal L_{\mathrm{balance}}\nonumber\notag\\
 &+\lambda_s\mathcal L_{\mathrm{separation}}
 +\lambda_h\mathcal L_{\mathrm{sharpness}}.
\end{align}
The auxiliary terms and their gradient handling are detailed in Appendix~\ref{app:implementation}.

\paragraph{Single-stage joint optimization.}
Let $\mathcal L_S=\mathcal L_{\mathrm{rank}}(z_S)$, $\mathcal L_{\mathrm{pref}}=\mathcal L_{\mathrm{rank}}(z_P)$, and $\mathcal L_{\mathrm{fused}}=\mathcal L_{\mathrm{rank}}(z)$. With both specialists and the coordinator enabled, the loss for every training batch is
\begin{align}
 \mathcal L_{\mathrm{DL}}={}&\frac{\mathcal L_S+\mathcal L_{\mathrm{pref}}+\mathcal L_{\mathrm{fused}}}{3}
 +\mathcal L_P\notag\\
 &+\lambda_{\mathrm{con}}\mathcal L_{\mathrm{con}}
 +\lambda_{\mathrm{div}}\mathcal L_{\mathrm{div}}.
 \label{eq:single_stage_loss}
\end{align}
For module ablations, the first term is the mean ranking loss over the enabled score heads; preference auxiliary and contrastive terms apply only when $P$ is enabled, and diversity applies only when both specialists are enabled. The diversity term discourages alignment between specialist states, while the contrastive term aligns preference states with immediate next-item vectors. Their formulas are given in Appendix~\ref{app:implementation}. All enabled online modules, the shared item projection, and optional LightGCN embeddings receive gradients from the first batch. Training uses this loss for the configured number of epochs, without a specialist warm-up, a separate coordinator stage, or policy-gradient updates. The pretrained Mamba text encoder remains frozen throughout.

\section{Experiments}
\label{sec:experiments}
We evaluate RIBS on four Amazon Reviews 2023 categories using full-catalog Recall and NDCG. Our central ablations ask whether the short-term sequence encoder and preference transition encoder complement each other, and whether adding direct item-level long-term memory helps the combined model. We then examine history-length cohorts and sensitivity to the recent window, preference granularity, and auxiliary objectives. The ver5 tables use completed run artifacts with default 	exttt{S1\_P1\_G1\_C1}, $W=4$, and $M=32$. Dataset construction, evaluation details, configurations, and run provenance are given in Appendices~\ref{app:dataset_protocol}, \ref{app:implementation}, and \ref{app:runs}. All tabulated results are single-seed point estimates.

\subsection{Discussion}
The ver5 results support the coordinated short-term and full-history preference configuration in the displayed component comparison. All results are single-seed offline point estimates; they do not establish statistical significance or causal attribution to individual mechanisms.

\section{Conclusion}
We presented RIBS, which combines cached Mamba text representations, short-term behavior, full-history preference transitions, and coordination. The default ver5 configuration is $S=P=G=C=1$, $W=4$, and $M=32$. It achieves the highest displayed NDCG@10 among the evaluated component configurations in all four categories.

\section*{Limitations}
The evidence is limited to existing offline runs with one recorded seed per configuration. There are no confidence intervals, significance tests, or verified matched external baseline reruns. Overall and cohort scores are available from the same restored models for all displayed ver5 configurations. Long-horizon, auxiliary-coefficient, and graph-depth controls are unavailable. Some duplicate runs predate explicit history-mode metadata; selecting the later auditable runs improves traceability but does not establish bitwise reproducibility. The saved artifacts do not pin every run to an immutable source revision, and the suite does not persist model weights.

The ablations change more than parameter presence. Disabling specialist or coordinator modules changes model capacity and optimization. All reported variants retain graph information and category-specific ranking priors. Separate controls are needed to attribute improvements to semantic features, the preference objectives, coordination, or the priors. Although state updates scale linearly with sequence length, we have not measured end-to-end latency, peak memory, energy use, or training cost under matched hardware.

The evaluation is transductive and based on per-user chronological splits. Count filtering and catalog construction use the full observed data before splitting. Missing metadata may fall back to review content assembled before the split, potentially exposing information unavailable at recommendation time; the frequency and impact of this fallback have not been audited. Thus excluding held-out events from graph and prior construction is not a complete temporal leakage audit. The single-pass count filter also differs from iterative 5-core protocols.

Prototype transitions are self-supervised signals derived from learned item embeddings. Their identities are not human-interpretable categories, and high transition probability need not indicate a real change in personal taste. The experiments do not establish explanation faithfulness, conversational recommendation quality, cold-start generalization, or multilingual robustness. Finally, logged reviews do not describe exposure propensities or responses to alternative recommendations. Offline ranking gains do not establish causal improvements in satisfaction, retention, fairness, or user welfare.

\section{Methods for the Preliminary Diagnostics}
\label{app:preliminary_diagnostics}

\paragraph{Evaluation sample and interaction lag.}
We analyze All Beauty, Baby Products, Sports and Outdoors, and Toys and Games using the same one-pass minimum-five-interaction filter and chronological leave-two-out split as the main experiments (Appendix~\ref{app:dataset_protocol}). For each test prediction, the observed history contains the training interactions followed by the validation item; the held-out test item is the target. We retain at most the last 100 observed interactions. Lag $\ell=1$ denotes the final item in this input, and lag counts interactions rather than elapsed time. The text-based diagnostics in panels (a), (c), and (d) sample up to 2,000 users uniformly without replacement from those eligible for both holdouts, with seed 25252. All 1,457 eligible All Beauty users are included; the other three categories each contribute 2,000 users. Panel (b) instead selects up to 2,000 equally spaced users from the sorted eligible set. The two selection rules need not yield identical users, so comparisons across panel types are descriptive.

\paragraph{Text representation and matched controls.}
For panels (a), (c), and (d), item text is mapped to a 1,024-dimensional feature-hashing representation using word unigrams and bigrams, English stop-word removal, nonnegative hashing, and $\ell_2$ normalization. Let $v_i$ be the resulting unit vector for item $i$; zero vectors are excluded. These diagnostic vectors are distinct from the frozen Mamba and LightGCN features used by the trained ranker. Up to 20,000 distinct items observed in training are sampled uniformly as the reference pool. Training-item frequencies $n_i$ are divided into five popularity bins using the empirical $0.2$, $0.4$, $0.6$, and $0.8$ quantiles of $\log(1+n_i)$, with ties assigned to the higher bin. For a historical item $h_{u,\ell}$, we draw 20 training-reference controls from its popularity bin after excluding the user's observed history. An empty bin is widened successively to adjacent bins; sampling uses replacement only when fewer than 20 eligible controls remain. Controls with unusable text are discarded. The held-out target is not separately excluded from this control pool and may be sampled if it occurs among training-reference items.

A separate cosine baseline is estimated within each category from 100,000 draws of distinct item pairs from the full processed catalog, retaining pairs with nonzero text vectors. Draws may repeat across pairs. Let $\mu_D$ and $\sigma_D$ be the sample mean and sample standard deviation, respectively, with the latter using denominator $N-1$. We use $s(i,j)=v_i^\top v_j$ and $z_D(i,j)=[s(i,j)-\mu_D]/\sigma_D$. The full catalog defines this normalization, whereas controls and preference-proxy fitting use training items.

\paragraph{Panel (a): semantic alignment.}
For target $y_u$ and the usable matched-control multiset $R_{u,\ell}$, the position-level excess alignment is
\begin{equation}
 d^{\mathrm{sem}}_{u,\ell}
 =z_D(h_{u,\ell},y_u)
 -\frac{1}{|R_{u,\ell}|}\sum_{r\in R_{u,\ell}}z_D(r,y_u).
 \label{eq:prelim_semantic}
\end{equation}
The common centering term cancels, so this equals the raw excess cosine divided by $\sigma_D$. A position is excluded if the target, historical item, or every sampled control has unusable text, or if no control is eligible. We group lags into $[1,1]$, $[2,2]$, $[3,4]$, $[5,8]$, $[9,16]$, $[17,32]$, $[33,64]$, and $[65,100]$. For bin $B$, let $\mathcal J_{u,B}$ be user $u$'s usable positions and $\mathcal U_B$ the users with at least one such position. Each user contributes one within-bin mean, and the plotted estimate is
\begin{equation}
 \bar d_B=\frac{1}{|\mathcal U_B|}\sum_{u\in\mathcal U_B}
 \frac{1}{|\mathcal J_{u,B}|}\sum_{\ell\in\mathcal J_{u,B}}
 d^{\mathrm{sem}}_{u,\ell}.
 \label{eq:prelim_bin_mean}
\end{equation}
Shading shows the $2.5$th and $97.5$th percentiles of 2,000 bootstrap means obtained by resampling users with replacement, using seed $25252+\min(B)+\max(B)$ for each bin. Points lie at bin midpoints on a linear lag axis; the horizontal zero line denotes equality with matched controls. This statistic measures text association, not ranking accuracy.

\paragraph{Panel (b): trained-model history-item influence.}
This diagnostic uses a single full-history Mamba sequence branch with LightGCN item features; the short-term and preference branches and coordinator are absent. The pretrained Mamba-130M text encoder is frozen, while the ranker uses dimension 128 and rank-16 low-rank residuals with scale 32 and dropout 0.05. Item text is truncated to 32 tokens and histories to 100 interactions. The model is trained for three joint-ranking epochs with batch size 128 and learning rate $5\times10^{-5}$, then restored to the state with the best validation NDCG@10. The training transition caps for the four categories, in the order above, are $0.5$, $1.5$, $1.0$, and $1.5$ million; their candidate counts are 64, 192, 256, and 192. Validation is performed once per epoch on all eligible validation users. Graph construction and any count-based priors use training interactions only.

For each selected test user, we sample up to 64 distinct negatives uniformly from the catalog, excluding the target and observed items (seed 25252). The same negative set $N_u$ is used for the full history and every single-position deletion. We use the restored model's raw score $f(i\mid H)$, without the popularity or transition priors used in full-catalog evaluation, to define
\begin{align}
 m_u(H)&=f(y_u\mid H)-\frac{1}{|N_u|}\sum_{n\in N_u}f(n\mid H),\\
 \Delta_{u,\ell}&=m_u(H_u)-m_u(H_u\setminus\{h_{u,\ell}\}).
 \label{eq:prelim_influence}
\end{align}
The deletion shortens the input sequence. A positive $\Delta_{u,\ell}$ means that retaining the item increases the target's margin over these fixed negatives; it is not a change in full-catalog Recall or NDCG. At each exact lag, we plot the user mean and a 95\% percentile interval from 2,000 user-bootstrap replicates, seeded $25252+\ell$. The combined figure displays lags with at least 100 contributing users; the separate all-position display retains sparser lags. Margin scales are not calibrated across categories.

\paragraph{Panel (c): cumulative positive semantic alignment.}
Using the same position-level values as panel (a), set $a_{u,\ell}=\max(d^{\mathrm{sem}}_{u,\ell},0)$ for usable positions and zero otherwise, and let $A_u=\sum_{\ell=1}^{100}a_{u,\ell}$. Users with $A_u=0$ are excluded. The coverage at the most recent $k$ positions is
\begin{equation}
 C_u(k)=100\,\frac{\sum_{\ell=1}^{k}a_{u,\ell}}{A_u},
 \qquad 1\leq k\leq100.
 \label{eq:prelim_coverage}
\end{equation}
The curve is the unweighted mean of $C_u(k)$ across included users. Its band is the cross-user $25$th--$75$th percentile range, rather than a confidence interval. The combined figure displays $k\leq20$ and marks 80\%; the separate coverage plot displays all 100 positions and marks 50\%, 80\%, and 90\%. These percentages quantify the distribution of positive excess text similarity, not model attribution or recommendation accuracy.

\subsection{Panel (d): Preference-Proxy Match}
\label{app:preliminary_match}
We fit 32 MiniBatchKMeans groups to at most 10,000 nonzero training-reference text vectors (seed 25252, batch size at most 1,024, three initializations, at most 100 iterations). The fitted groups assign each usable item a hard label $c(i)\in\{0,\ldots,31\}$. They are text-derived proxies, independent of the RIBS preference prototypes, next-item ranking supervision, and Mamba or LightGCN features.

Let $\mathcal C_u$ be the distinct labels among usable items in the entire observed history of user $u$. Users with an unusable target or no usable history label are excluded. If one label is selected uniformly from $\mathcal C_u$, its probability of matching the target is
\begin{equation}
 b_u=\frac{\mathbf 1[c(y_u)\in\mathcal C_u]}{|\mathcal C_u|}.
 \label{eq:prelim_preference_baseline}
\end{equation}
This baseline is zero when the target label is absent and generally differs from $1/32$. At each usable, control-matched position, define $d^{\mathrm{pref}}_{u,\ell}=\mathbf 1[c(h_{u,\ell})=c(y_u)]-b_u$. Using the same within-user then across-user aggregation as panel (a), the plotted excess agreement in percentage points is
\begin{equation}
 E_B=\frac{100}{|\mathcal U_B|}
 \sum_{u\in\mathcal U_B}\frac{1}{|\mathcal J_{u,B}|}
 \sum_{\ell\in\mathcal J_{u,B}}d^{\mathrm{pref}}_{u,\ell}.
 \label{eq:prelim_preference_match}
\end{equation}
The shaded interval uses the same user-bootstrap procedure as panel (a); zero indicates agreement at the user's uniform-label chance level. The confidence intervals in panels (a), (b), and (d) condition on the selected users and fixed diagnostic representations; they do not capture variation across model-training seeds.

\paragraph{Cohort displays and plotting conventions.}
The additional two-panel alignment and preference displays compare all users with a fixed-history cohort requiring at least 16 observed interactions. Estimates for fixed minimum lengths of 8 and 32 are computed in the same way, retaining only bins whose upper edge does not exceed the minimum length. A category curve is shown only where a point has at least 100 contributing users; consequently, Baby Products does not appear in the fixed-16 panel. A separate paired contrast compares each qualifying user's lag-1 value with that user's mean over lags 9--16, then bootstraps these within-user differences.

Across the four-category plots, All Beauty is blue with a solid line and circles, Baby Products orange with a dashed line and squares, Sports and Outdoors green with a dash-dot line and triangles, and Toys and Games pink with a dotted line and diamonds. Category estimates are overlaid without pooling or smoothing. Binned estimates use the arithmetic bin midpoint on a linear x-axis; influence uses exact integer lag. Zero-reference lines appear for excess alignment, excess preference agreement, and margin influence. The combined coverage display is restricted visually to $k=1,\ldots,20$, while its denominator still includes up to 100 positions. The individual influence display includes all available lags; the individual coverage display uses the full $k=1,\ldots,100$ range. The inverse-history display retains the same estimators and visual conventions, but reverses each capped input history before calculating lags and retrains the influence model on that order. Thus, its lag 1 is the originally oldest interaction within the retained suffix; chronological targets, splits, graph, and training-item priors remain unchanged.

\label{app:preliminary_inverse}

To distinguish the relevance of genuinely recent interactions from the model's tendency to rely on nearby input positions, we truncate each history to its latest 100 interactions, reverse that suffix, retrain the same Mamba+LightGCN configuration, and repeat the diagnostics. The target, chronological split, graph, and training-item priors are held fixed. The lowest-lag positions in this control now contain the oldest items within that suffix. In Figure~\ref{fig:preliminary_inverse}a, these positions do not have the strongest semantic alignment with the next item; alignment can be higher at later reversed positions. Their direct contribution to the sampled-slate ranking margin is also small or negative at lag 1 in Figure~\ref{fig:preliminary_inverse}c, whereas the original-order analysis has a pronounced lag-1 influence peak in Figure~\ref{fig:preliminary}b. Nevertheless, Figure~\ref{fig:preliminary_inverse}d shows that cumulative positive text-signal coverage still rises rapidly over the lowest reversed lags. The retrained model therefore remains concentrated on nearby inputs even when those inputs provide little measured text-level support for the target. This pattern is consistent with a learned positional tendency, rather than an explanation based only on the predictive value of the most recent interactions. The control does not isolate which model component causes that tendency.

\section{Dataset and Evaluation Protocol}
\label{app:dataset_protocol}
We analyze completed Amazon Reviews 2023 runs on All Beauty, Baby Products, Sports and Outdoors, and Toys and Games \citep{BLaIR}. All Beauty is a distinct Amazon category from Beauty and Personal Care. Item text concatenates available titles, subtitles, categories, features, and descriptions. Missing metadata can fall back to review text or an item identifier. The Amazon loader treats review events as implicit interactions and does not apply the rating threshold used by other dataset adapters.

Preprocessing counts raw user and item interactions and applies a minimum count of five once. It is not iterative 5-core filtering: removing low-frequency items may leave a user with fewer than five interactions. Eligible sequences reserve their penultimate and final events for validation and test. Test histories include the validation item, but training targets, graph edges, and priors exclude both held-out events. Filtering and catalog indexing precede the split, so this is a transductive per-user chronological protocol, not a globally time-separated deployment simulation.

Evaluation ranks against the complete processed catalog for every eligible user. Previously observed items are masked, except that a repeated gold item remains eligible. Ties use the pessimistic rank equal to the number of candidate scores greater than or equal to the gold score. With one relevant item per user, Recall@$K$ equals Hit@$K$, and NDCG@$K$ is $\mathbf 1[r\leq K]/\log_2(r+1)$ averaged over users. We report Recall and NDCG at 5 and 10, with no evaluation-user subsampling.

For cohort analysis, short histories contain at most 10 events and long histories contain more than 10, measured on each complete filtered sequence before validation/test holdout. Membership is fixed across evaluation splits and independent of the model's context window. Each model is trained on both groups together. Short-history users account for approximately 82--85\% of evaluated users in every category.

\section{Implementation Details}
\label{app:implementation}
\paragraph{Item features and adaptation.}
The frozen Mamba text encoder receives each item's text prefixed with ``Preference-aware product representation: ''. We mean-pool content-token hidden states, excluding padding and prefix tokens. If truncation leaves no content tokens, we pool non-padding tokens instead. Only hidden states are computed, without vocabulary prediction logits; the resulting $f_i$ is cached for ranker training and evaluation. The item projection $W_f$ is trainable. Each online LoRA residual $\mathcal R_j$ uses $A_j\in\mathbb R^{r\times d_{\mathrm{in},j}}$ and $B_j\in\mathbb R^{d_{\mathrm{out},j}\times r}$. Each $B_j$ starts at zero, and dropout is inactive at inference. The item projection, optional graph embeddings, preference prototypes and prediction heads, and state-update biases remain trainable alongside these residuals.

The shared collaborative item vector $g_i$ comes from a two-layer LightGCN on training interactions, averaging the initial item embedding and both propagated layers. It is combined with the cached text feature as
\begin{equation}
 e_i=\norm{\norm{W_f f_i}+\norm{g_i}},
\end{equation}
where $\norm{x}=x/\max(\lVert x\rVert_2,\epsilon)$. Without LightGCN, $e_i=\norm{W_f f_i}$. Validation and test interactions are excluded from graph construction and the count-based priors.

\paragraph{Selective-state computations.}
For each agent $m\in\{S,P\}$, the retention factor, candidate state, and output gate in Eq.~\eqref{eq:state_update} are computed elementwise from the current input as
\begin{align}
 a_k^{(m)}&=\exp\!\Bigl[-\min\!\Bigl\{
    \operatorname{softplus}\!\bigl(b_{\delta,m}\notag\\
 &\qquad+\mathcal R_{\delta,m}(y_k^{(m)})\bigr),12\Bigr\}\Bigr],\notag\\
 \widetilde h_k^{(m)}&=\tanh\!\bigl(y_k^{(m)}\notag\\
 &\qquad+\mathcal R_{\mathrm{cand},m}(y_k^{(m)})\bigr),\notag\\
 g_k^{(m)}&=\sigma\!\left(\mathcal R_{\mathrm{gate},m}(y_k^{(m)})\right).
\end{align}
The minimum caps the positive softplus output at 12 before exponentiation. Each agent has its own state-update bias and LoRA residuals; the output gate and recurrence are as shown in Eq.~\eqref{eq:state_update}. The recurrent state starts at zero, while padding leaves the state and output unchanged. Four residuals per specialist control decay, candidate state, output gate, and final state correction; the preference specialist uses a fifth residual for reconstructed preference state. The decay biases initialize $a_k^{(S)}=\exp(-0.5)$ and $a_k^{(P)}=\exp(-0.2)$ before the residuals learn. Prototype indices have no predetermined semantics or cross-run alignment.

\paragraph{Coordinator and inference.}
The coordinator owns three residual modules for mixing, state construction, and candidate scoring, giving twelve distinct low-rank residual modules in the default model. Its context weights and intercept start at zero, while $\theta_P$ starts from the configured preference mixing weight; the mixing residual can subsequently change both logits. Optional configurations can disable either specialist, the graph embeddings, or the coordinator. Without the coordinator, two enabled specialists use a fixed configured score mixture; a sole specialist scores directly. Disabled modules have no trainable parameters in that configuration. At inference, training-only popularity and transition priors give
\begin{equation}
 \widetilde z(u,i)=z(u,i)+\alpha_p p_i+\beta_t\log(1+n_{i_t,i}),
\end{equation}
where $p_i$ is standardized log-one-plus training popularity and $n_{i_t,i}$ counts adjacent training transitions from the last observed item. Missing transitions contribute zero, and the coefficients are configured by category. All reported scores include these priors; their contribution is not isolated from that of the neural model.

\paragraph{Ranking and auxiliary losses.}
Training targets are later logged interactions from the training portion of each sequence; validation and test targets are held out. Known training positives are excluded from negative selection, and the hard-negative fraction increases during warm-up. If fewer than $F$ future items remain, the final available target fills unused target slots with zero target weight. Ranking softmax uses the constructed slate, where positions may share an item identity. An optional full-catalog supervised mode scores all items. For prototype learning, $\mathcal L_{\mathrm{balance}}$ is a KL penalty between the batch mean of non-detached next-item assignments $q(i_{t+1})$ and the uniform distribution; $\mathcal L_{\mathrm{separation}}$ penalizes $CC^\top-I$; and $\mathcal L_{\mathrm{sharpness}}$ uses normalized assignment entropy. Unlike detached prediction targets, these three terms pass gradients through assignments or prototypes. The diversity loss averages $(s_S^\top s_P)^2$ over a batch. With $y_u$ the immediate next item and $N$ the batch size, contrastive alignment is
\begin{equation}
 \mathcal L_{\mathrm{con}}=-\frac{1}{N}\sum_{u=1}^{N}
 \log\frac{\sum_{v:y_v=y_u}\exp(s_{P,u}^\top e_{y_v}/\tau_c)}
 {\sum_{v=1}^{N}\exp(s_{P,u}^\top e_{y_v}/\tau_c)}.
\end{equation}
The numerator includes all batch targets with the same item identity; $\tau_c=0.1$.

\paragraph{Single-stage supervised optimization.}
With both specialists and the coordinator enabled, each batch contributes the three ranking losses in Eq.~\eqref{eq:single_stage_loss}, the preference auxiliary loss, contrastive alignment, and state diversity. More generally, let $\mathcal A$ contain the active ranking heads: short-term and preference when enabled, plus the coordinator when enabled or when it supplies the graph-only score. The implementation computes
\begin{equation}
 \mathcal L_{\mathrm{DL}}=\frac{1}{|\mathcal A|}\sum_{m\in\mathcal A}\mathcal L_{\mathrm{rank}}(z_m)
 +\mathbf 1_P\bigl(\mathcal L_P+\lambda_{\mathrm{con}}\mathcal L_{\mathrm{con}}\bigr)
 +\mathbf 1_S\mathbf 1_P\lambda_{\mathrm{div}}\mathcal L_{\mathrm{div}}.
\end{equation}
Here $\mathbf 1_S$ and $\mathbf 1_P$ indicate enabled specialists. Disabled agents contribute neither branch losses nor trainable parameters. The short-term agent, preference agent, coordinator, item projection, and optional graph embeddings are optimized together from the first batch; the frozen Mamba text encoder only supplies cached item features. The training configuration uses the complete supervised objective for every epoch and selects the best validation checkpoint. It does not sample rankings for a policy objective.

The single-stage configuration uses \texttt{state-spaces/}\allowbreak\texttt{mamba-130m-hf}, frozen 768-dimensional text features, a maximum text length of 32 tokens including the prompt, a 128-dimensional ranker, two graph layers, 32 preference prototypes, and prototype temperature 0.2. Low-rank modules use rank 16, scale 32, and dropout 0.05. Training and evaluation batch sizes are 128 and 64. The completed default artifacts configure six specialist/supervised epochs and zero joint epochs, training all enabled modules at learning rate $10^{-4}$; the reported default recent-item window is four and its maximum available history is 100 items.

Future targets use $F=3$ and $\eta=0.5$. The negative pool multiplier is 12, the target hard-negative fraction is 0.75, and its warm-up lasts two epochs within the single stage. Preference loss coefficients $(\lambda_p,\lambda_t,\lambda_b,\lambda_s,\lambda_h)$ are $(0.2,0.1,0.01,0.01,0.05)$; contrastive and diversity coefficients are 0.05 and 0.02. Validation NDCG@10 selects the restored best state. The saved configurations set early-stopping patience to six and validation intervals to 250 steps. The launch configuration uses seed 25252.
