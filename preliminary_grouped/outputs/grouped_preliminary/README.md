# Five preliminary figures by temporal group

Figures 1–4 plus the all-group influence supplement are provided as PNG/PDF/SVG. Each subset JSON contains group-length statistics and all five figure estimates. plotted_data.csv includes all computed groups, including those hidden by the main n≥100 filter.

Groups split only after consecutive gaps >30 days. Figure2 retains original semantic cluster labels and chance baseline. Figure3/S1 average individual item-deletion effects inside each time group; they do not measure deleting the entire group. Fixed-K16 means ≥16 original items. Raw data and original figures are unchanged.
